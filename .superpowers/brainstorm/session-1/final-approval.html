Resumo do Design Final

Eis o que vamos construir para o módulo de Clientes.

Especificação: Módulo Clientes

Funcionalidades

  • Lista de empresas à esquerda com filtro de busca.
  • Painel central com dados da empresa (CNPJ, Endereço, etc.).
  • Seção "Responsável Comercial" editável.
  • Histórico de conversas do Agente n8n / Supabase.
  • Botão "+ Novo Cadastro" manual.

Considerações

  • Precisaremos de uma integração com Supabase p/ as respostas reais.
  • O layout será focado em desktop devido à densidade de informações.
